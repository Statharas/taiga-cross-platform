# TODO and unfinished-screen audit

This audit separates user-facing unfinished screens from internal `@TODO`
comments. It was generated by scanning `src` for `TODO`, `not implemented`,
`placeholder`, and related strings, then mapping them back to visible UI.

| Area | Evidence | User impact | Requirement link |

| Search submit for MyAnimeList/Kitsu | `taiga_sync::searchTitle()` now routes to MAL/Kitsu search endpoints. | Backend search exists for all three services; live service tests still need authenticated/network fixtures. | Search submit requirement. |
